## SECTION: Platform Overview

**Odito** is a comprehensive AI-powered SEO analytics platform that combines traditional SEO analysis with cutting-edge AI visibility scoring to help businesses optimize their websites for both search engines and AI systems like ChatGPT, Claude, and other large language models.

### Platform Purpose
The platform analyzes websites across multiple dimensions:
- Traditional SEO factors (technical, on-page, performance)
- AI visibility and readiness for LLM citation
- Voice search optimization
- Topical authority assessment
- Entity recognition and structured data

### Core Value Proposition
Odito bridges the gap between conventional SEO and the emerging field of AI optimization (AEO - Answer Engine Optimization), helping businesses prepare for the future of search where AI assistants play an increasingly important role in content discovery and recommendation.

## SECTION: SEO Concepts

### Canonical Tags
**What they are**: HTML elements that specify the preferred version of a page when multiple URLs have similar content
**Why they matter**: Prevent duplicate content issues, consolidate SEO signals, guide search engines to the primary page
**How to fix**: Add canonical link tags pointing to the preferred URL, ensure self-referencing canonicals, avoid conflicting canonicals

### Sitemap Validation
**What it is**: Process of verifying XML sitemap structure and accessibility
**Why it matters**: Ensures search engines can discover and index all important pages
**How to fix**: Create proper XML sitemap, submit to search engines, ensure all important URLs are included, check for errors

### Robots.txt
**What it is**: Text file that instructs search engine crawlers which pages or sections to crawl or not crawl
**Why it matters**: Controls crawl budget, prevents indexing of sensitive content, guides crawler behavior
**How to fix**: Create proper robots.txt file, allow important content, block admin/private areas, test with Google tools

### HTTPS Redirect
**What it is**: Automatic redirection from HTTP to HTTPS secure protocol
**Why it matters**: Security requirement, ranking factor, user trust signal
**How to fix**: Install SSL certificate, configure server redirects, update internal links, ensure mixed content is resolved

### Heading Structure
**What it is**: Hierarchical organization of content using H1, H2, H3, etc. tags
**Why it matters**: Content organization, SEO signals, accessibility, user experience
**How to fix**: Use single H1 per page, maintain logical hierarchy, include keywords in headings, avoid skipped levels

### Structured Data (Schema)
**What it is**: Standardized format for providing information about page content to search engines
**Why it matters**: Enhanced search results, rich snippets, better understanding by AI systems
**How to fix**: Implement relevant schema types, validate markup, ensure consistency with page content

### Meta Tags
**What they are**: HTML elements that provide metadata about pages to search engines
**Why they matter**: Search result appearance, click-through rates, content understanding
**How to fix**: Write unique title tags (50-60 chars), compelling meta descriptions (150-160 chars), include target keywords

### Mobile Friendliness
**What it is**: Measure of how well a website works on mobile devices
**Why it matters**: Mobile-first indexing, user experience, mobile rankings
**How to fix**: Use responsive design, ensure readable text, accessible navigation, fast loading on mobile

### Core Web Vitals
**What they are**: Specific metrics that measure user experience: LCP, FID, CLS
**Why they matter**: Ranking factors, user experience signals
**How to fix**: Optimize images, reduce server response time, minimize layout shifts, optimize JavaScript

## SECTION: AI Visibility

### AI Visibility Score
**What it is**: Overall score (0-100) measuring how likely content is to be cited by AI systems
**Why it matters**: Predicts AI search performance, indicates content readiness for LLM consumption
**How to improve**: Focus on entity richness, content clarity, structured data, and topical authority

### LLM Readiness
**What it measures**: How well content is structured for Large Language Model processing
**Components**: Content structure clarity, readability optimization, semantic markup
**How to improve**: Use clear heading hierarchy, write in accessible language, include structured data, answer common questions

### Topical Authority
**What it measures**: Depth and breadth of expertise in specific subject areas
**Components**: Entity richness, topical depth, content comprehensiveness
**How to improve**: Cover topics comprehensively, include relevant entities and concepts, demonstrate expertise through detailed content

### Voice Intent Optimization
**What it measures**: How well content matches voice search queries and conversational intent
**Components**: Intent clarity, conversational language, question-answer format
**How to improve**: Include natural language phrases, structure content as Q&A, optimize for long-tail conversational queries

### Entity Recognition
**What it measures**: Presence and quality of identifiable entities (people, places, organizations, concepts)
**Components**: Entity count, entity types, entity relationships
**How to improve**: Include named entities, use structured data for entities, build clear entity relationships

### Citation Probability
**What it measures**: Likelihood of content being cited by AI systems in responses
**Components**: Authority signals, content quality, source credibility
**How to improve**: Build authority, provide accurate information, include citations and references, maintain content freshness

### AEO (Answer Engine Optimization)
**What it is**: Optimization strategy focused on appearing in AI-generated answers and voice responses
**Why it matters**: AI systems are becoming primary information sources
**How to implement**: Structure content as direct answers, use FAQ format, optimize for question queries, provide concise responses

### GEO (Generative Engine Optimization)
**What it is**: Optimization for generative AI engines that create original responses
**Why it matters**: Generative AI is changing how users find information
**How to implement**: Focus on comprehensive, authoritative content, include diverse perspectives, provide unique insights

### Technical SEO Questions

**Q: What is a canonical tag and why is it important?**
A: A canonical tag tells search engines which version of a page should be treated as the main version. This prevents duplicate content issues and helps consolidate SEO signals.

**Q: How do I fix HTTPS redirect issues?**
A: Install an SSL certificate, configure your server to redirect HTTP to HTTPS, update internal links to use HTTPS, and resolve any mixed content issues.

**Q: What are Core Web Vitals?**
A: Core Web Vitals are specific metrics that measure user experience: Largest Contentful Paint (LCP), First Input Delay (FID), and Cumulative Layout Shift (CLS). They are important ranking factors.

**Q: How important is mobile friendliness for SEO?**
A: Extremely important. Google uses mobile-first indexing, meaning it primarily uses the mobile version of your site for ranking and indexing.

**Q: What is structured data and why do I need it?**
A: Structured data is standardized code that helps search engines understand your content better. It can lead to enhanced search results (rich snippets) and better visibility in AI systems.

### AI Visibility Questions

**Q: What is AI visibility scoring?**
A: AI visibility scoring measures how likely your content is to be cited by AI systems like ChatGPT, Claude, and other large language models.

**Q: Why is AI optimization important?**
A: AI systems are becoming primary information sources. Optimizing for AI ensures your content appears in AI-generated answers and recommendations.

**Q: What is the difference between AEO and traditional SEO?**
A: AEO (Answer Engine Optimization) focuses on appearing in direct answers and AI-generated responses, while traditional SEO focuses on search engine rankings.

**Q: How is AI visibility score calculated?**
A: The score is based on multiple factors including LLM readiness, topical authority, entity richness, voice intent optimization, and citation probability.

**Q: What are entities and why do they matter for AI?**
A: Entities are specific, identifiable things like people, places, organizations, and concepts. AI systems use entities to understand relationships and context in content.

### Audit and Analysis Questions

A: Audit time depends on website size. Small sites (under 100 pages) typically take 10-30 minutes, while larger sites may take several hours.

**Q: What does the SEO Health score mean?**

**Q: How do I prioritize which issues to fix first?**
A: Focus on critical technical issues first (HTTPS, crawlability, indexing), then high-impact on-page issues (titles, meta descriptions), followed by performance optimizations.

**Q: Can I audit competitor websites?**

**Q: How accurate are the AI visibility predictions?**
A: Our AI visibility scoring is based on extensive analysis of how AI systems process and cite content. While not perfect, it provides strong guidance for AI optimization.

## SECTION: Troubleshooting

### Common Technical Issues

**Problem: Audit fails to start**
- Check that the website URL is accessible and not blocked by firewalls
- Ensure the URL format is correct (include https://)
- Verify the website doesn't require authentication
- Try again after a few minutes

**Problem: Slow audit performance**
- Large websites naturally take longer to audit
- Check server response times for the target website
- Consider running audits during off-peak hours
- Contact support if audits consistently timeout

**Problem: Incomplete or missing data**
- Ensure the audit has fully completed before viewing results
- Check that all important pages are accessible to crawlers
- Verify robots.txt isn't blocking important content
- Re-run the audit if data appears incomplete

**Problem: AI visibility score seems inaccurate**
- Review the detailed breakdown to understand scoring factors
- Ensure content is properly structured with headings and clear language
- Check that structured data is implemented correctly
- Allow time for AI optimization improvements to be reflected

### Account and Access Issues

**Problem: Can't log in to account**
- Verify email and password are correct
- Check that account is verified (check email for verification message)
- Clear browser cache and cookies
- Use password reset if needed

**Problem: Can't access specific projects**
- Ensure you're logged into the correct account
- Check that projects haven't been archived or deleted
- Verify team permissions if using a corporate account
- Contact account owner for access requests

**Problem: Billing or subscription issues**
- Check payment method is valid and current
- Verify subscription plan is active
- Review billing history for failed payments
- Contact billing support for payment issues

### Data and Reporting Issues

**Problem: Export reports not working**

- Verify you have sufficient permissions for the project

**Problem: Data not updating after changes**

**Problem: Inconsistent scores between audits**
